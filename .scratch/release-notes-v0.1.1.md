这个版本只改协议和文档，功能与 v0.1.0 完全相同。

## 协议变更

项目从 MIT 改为 **GPL-3.0-only**。这意味着下游的修改版也必须继续开源。

v0.1.0 及更早版本是按 MIT 发布的，那份授权对已经拿到副本的人继续有效，无法撤回。

## 文档

README 重写：新增协议、版本、语言、单文件大小四枚徽章；补充「为什么用它」；配置字段改为表格；新增排查小节。

## 下载

- 文件：`easinput-v0.1.1-win-x64.exe`
- 大小：约 66MB
- 自包含单文件，Windows 10/11 x64（只在 Windows 11 上实测过），无需安装 .NET。
- SHA256：`183f6f64884fed9fecb7c6479ba21cf22ba98154b367ec241a5a22959e621337`

exe 未签名，首次运行会被 SmartScreen 拦一下。点「更多信息」，再点「仍要运行」即可。

## 升级

先在托盘菜单里选「退出」，再用新的 exe 覆盖旧文件。

## 已知限制

与 v0.1.0 相同（提权窗口/UAC/独占全屏/锁屏不支持；混合 DPI 多屏未逐屏验证；按键→显示 avg 57.7ms，高于 50ms 预算；exe 未签名；无自动更新），详见 v0.1.0 的 release notes。
