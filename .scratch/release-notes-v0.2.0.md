这个版本改锚点与触发：Chrome/Electron 里的气泡位置修好了，切换窗口时该弹就弹。

## 锚点：增加 MSAA 插入符层级

降级链由三级扩为四级：Win32 插入符 → MSAA `OBJID_CARET` → UIA `TextPattern` → 隐藏。

修复两个现场缺陷：

- **VS Code**：UIA 对折叠选区返回整行盒（1088×26），气泡被放到整行正中间；MSAA 返回真实插入符（1×27）。
- **ZCode 空输入框**：UIA 在空文档上没有任何矩形，输入第一个字之前不弹；MSAA 在空文档上也能给出插入符（1×26）。

所有候选矩形都要通过形状校验：折叠矩形只接受细条（宽 ≤ max(4, 高/2)），整行盒直接拒绝——宁可隐藏，也不把气泡放到行中间。

## 触发：切窗即提示

- 切到另一个能解析到插入符的窗口，会提示当前模式，**即使输入模式没变**。旧版只在模式变化时弹，同模式切窗静默，感觉像有冷却。
- 同一窗口、同一模式的 300ms 轮询仍不重复弹。
- 锚点解析移到后台线程，不再阻塞 UI；隐藏结果按 150ms 间隔重试，共 3 次，减少切换瞬间新窗口插入符尚未就绪造成的漏报。

## 已知边界

- **微信 4.x（`Weixin.exe`）不兼容**：主窗口是 Qt 自绘 + TSF，Win32 插入符、MSAA `OBJID_CARET`、UIA `TextPattern` 三条路径都拿不到插入符，气泡保持隐藏。这是已知边界，不是故障；不采用固定偏移或指针兜底，也不注入进程。
- 同一个窗口内把焦点移到另一个输入框、但输入模式没变时，不会弹；只有切换前台窗口才会。
