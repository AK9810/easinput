Windows 输入模式提示器 easinput 的首个可运行版本，预发布（prerelease）。切换中文、英文或 CapsLock 时，它会在文本插入符下方显示一个瞬时药丸徽标，告诉你此刻会打出什么。

## 下载

- 文件：`easinput-v0.1.0-win-x64.exe`
- 大小：约 66MB
- 自包含单文件，Windows 10/11 x64，无需安装 .NET（只在 Windows 11 上实测过）。首次启动会解压到 `%TEMP%\.net\easinput\`。
- SHA256：`848494e3174b0c7351666bc2f253e6769fbcf41c294eeb3981a5eab42dc1005c`

exe 未签名，首次运行会被 SmartScreen 拦一下。点「更多信息」，再点「仍要运行」即可。

## 这个版本做了什么

- **药丸徽标**：中文「拼」、英文小写「a」、英文大写「A」，蓝底 `#007AFF`，显示在插入符下方居中。
- **锚点逐级降级**：Win32 插入符 → UIA `TextPattern` → 指针（仅当指针位于焦点窗口内）→ 隐藏。
- **托盘菜单**：启用提示、开机自启、预览效果、打开配置文件、退出。
- **首次运行提示**：第一次双击启动会弹一次系统通知，说明程序在托盘里运行；之后不再弹。
- **重复双击**：再次双击 exe 会提示「已在运行」，不会静默退出。
- **开机自启**：默认关闭，需要时在托盘里打开。
- **配置便携优先**：exe 同目录有 `config.json` 就用它，否则用 `%APPDATA%\easinput\config.json`。
- **日志**：写到 `%APPDATA%\easinput\easinput.log`；把 `logLevel` 改成 `debug` 可看到每次状态读取与锚点降级。

## 已知限制

- 提权窗口（UIPI）、UAC 安全桌面、独占全屏、锁屏：不支持。
- 混合 DPI 多屏：定位只做了基本处理，尚未逐屏验证。
- 按键→显示：实测 42.6–68.9ms，avg 57.7ms（Debug 构建 / 12 逻辑核），高于 50ms 预算。主因是 30ms 的 IME 稳定延迟和 15.6ms 的定时器粒度。
- exe 未签名。
- 没有自动更新。

## 升级

先在托盘菜单里选「退出」，再用新的 exe 覆盖旧文件。
