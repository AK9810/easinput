# macOS 输入源徽标（参考规格）

本文记录"1:1 复刻"的目标值。数值来自 Sonoma 14 的 2× 截图实测、Apple 官方 2× 素材、
WWDC23 与 AppKit 文档；不确定的项单独标注。

## 它是什么

Sonoma 14 起，系统文本光标（`NSTextInsertionIndicator`）带一个**光标配件（cursor accessory）**，
贴在插入符下方，显示当前输入源的**短代码**，例如 `EN`、`ру`、`ع`、`あ`、`A`、`ES`。
AppKit 文档原话：光标配件用于指示"当前输入源语言、听写、Caps Lock"等状态；
语言变化时配件会"展开"成语言切换器。

**它不是品牌图标，也不是全名。** 全名列表是旧版/回退界面（深色竖排列表），与这个是两回事。

## 折叠态徽标

| 项 | 值 | 置信度 |
|---|---|---|
| 形状 | 药丸（capsule），圆角 = 高度/2 | 实测 |
| 高度 | **23–24 pt**（46–48 px @2×） | 实测，高 |
| 圆角 | **11.5–12 pt** | 实测，高 |
| 宽度 | 纯代码约 30–36 pt；带麦克风 61 pt；Caps Lock 徽标 30 pt | 实测+估算 |
| 填充 | 纯色系统蓝，**无模糊、无 vibrancy**。Caps Lock 徽标实测 `#007AFF`；语言徽标原始像素 `#3478F6`（同一蓝在不同色彩配置下的偏移） | 实测，高 |
| 边框 | 无 | 实测 |
| 内容 | 1–3 个字形，白色。拼音为「拼」（截图中直接可见） | 实测，高 |
| 字形尺寸 | 代码 `EN` 约 15×9 pt；Caps Lock `⇪` 13.5×13.5 pt | 实测，高 |
| 内边距 | 水平约 8–10 pt，垂直约 5 pt | 实测，中高 |
| 字体 | SF Pro，约 13 pt semibold，cap height 9 pt | 实测+推导 |
| 锚点 | 插入符**正下方**，水平居中 | 实测，高 |
| 与插入符间距 | **1–2 pt**（Apple 素材测量）～**3.5 pt**（本地截图测量） | 实测，存在口径差异 |
| 阴影 | 向下约 2 pt、模糊 8–10 pt、黑 15–20% | 像素梯度估算，中低 |
| 动画 | 语言变化时"展开/收起"；时长与缓动未公开，静态图无法测量 | 未知 |
| 边缘处理 | `NSTextCursorAccessoryPlacement` 有 `offscreenTop/Bottom/Left/Right/invisible` 等取值，说明存在贴边重定位；具体规则未公开 | 文档+未知 |

听写状态会在左侧加一个麦克风图标和 1 pt 分隔线——与本项目无关。

## Caps Lock 徽标

| 项 | 值 | 置信度 |
|---|---|---|
| 形状 | **同样是药丸**，30 × 23 pt | 实测 |
| 填充 | `#007AFF` | 实测 |
| 字形 | 白色描边 `⇪`（capslock 符号），13.5 × 13.5 pt，无文字 | 实测 |
| 生命周期 | **常驻**：Caps Lock 亮着就一直显示，不是瞬时 | 多方一致 |
| 交互 | **可点击**，点击关闭 Caps Lock | 多方一致 |
| 位置 | 与输入源徽标同一位置（插入符下方居中） | 实测 |

## 展开选择器（按住 Control+Space / Globe）

| 项 | 值 |
|---|---|
| 形态 | 同一 23 pt 高度的水平药丸；带麦克风 + 4 个代码时约 165 pt 宽 |
| 选中项 | 23 pt 蓝色圆形，白色代码 |
| 浅色 | 白色药丸 `#FEFEFE`，蓝色代码 |
| 深色 | 真实 Sequoia 截图：`#363636` 药丸，`#686868` 0.5 pt 边框，白色代码，蓝圆 |
| 触发 | 按住 Control 连按 Space；或 Globe 设为"切换输入源" |

这是**选择器**，不是切换后的徽标。两者不要混为一谈。

## 行为规则

- 触发：任何输入源变化都会弹徽标——快捷键、Caps Lock 切换、菜单栏选择、程序化切换（im-select）。
  键盘布局切换（美式 ↔ 德语）表现相同。
- 无焦点文本框时：通常**不显示**徽标（旧版会弹居中的大列表）。
- 时长：Apple 没有任何文档或设置项。旧版选择器是"按住期间显示、松手淡出"；徽标时长未公开。
- 打字是否让它消失：**不会**（有报告称徽标会卡住，Esc 可关）。
- 位置：插入符下方并略微偏右，会压住下一行文字——这是 macOS 用户普遍吐槽的点。
- **徽标只表达输入源身份，不表达中/英模式**：在同一个中文输入法内按 Shift 切中英，
  徽标显示的还是同一个「拼」，信息量不变。大小写由**另一个常驻 ⇪ 徽标**表达。

## 与 Windows 的映射

| macOS | Windows 对应 |
|---|---|
| 输入源短代码（拼/A/EN） | 中文态：输入法短代码或品牌图标；英文态：`a` / `A` |
| 系统蓝药丸 | 可复用；若要用品牌图标/品牌色则需取舍 |
| 下方居中 + 1–3.5 pt 间距 | 可直接复用 |
| 无模糊 | 正好——Windows 的 Acrylic 与逐像素透明分层窗口互斥，纯色填充反而是唯一正确解 |
| SF Pro | 不能合法打包到 Windows（Apple 字体许可禁止在非 Apple 系统使用/嵌入）；用 Segoe UI Variable 或 Inter 替代 |
| Caps Lock 常驻 ⇪ 徽标 | 与"三态模型用 A 表达大写"重复，见第三轮问题 |
| 贴边重定位 | 我们自己实现：顶部/底部/左右越界时翻转 |
